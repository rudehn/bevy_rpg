# Placeholder Sprites

When a new sprite is needed, create a brand new unique image that actually depicts the intended subject. Never copy or reuse existing sprite files — even as "placeholders."

Generate a unique PNG using Pillow that visually represents the actual subject. Draw recognizable shapes, colors, and details appropriate to the item. For tile sprites, the pattern must tile seamlessly. Never point a new asset at an existing sprite path.
